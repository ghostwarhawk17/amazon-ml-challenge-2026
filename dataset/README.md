# Put the official data here

The data files are too big for GitHub, so copy them in by hand:

```
dataset/
├── train/  train_source1.tsv, train_source2.tsv, train_source3.tsv, train_ground_truth.tsv
└── test/   test_source1.tsv, test_source2.tsv, test_source3.tsv
```

Then run `code\business_entity_resolution\run_pipeline.bat`.
